# A0 架构整理验收

日期：2026-10-08。范围：模块拆分、现有 v1 合同兼容、依赖边界与类型检查。目标方向见 [Agent 融合架构规划](./AGENT_ARCHITECTURE.md)。

## 交付

| 模块 | 职责 |
| --- | --- |
| `src/contracts/` | 现有文档/选区类型、操作/元素/键级/批量限制、工具拒绝码、桥接通道和路由名称 |
| `src/chemistry/` | 原有确定性执行器、基团注册、局部布局与完整意图核对 |
| `src/host/` | 文档存储、批注服务、工具注册、提示构建与宿主桥接 |
| `src/adapters/ketcher/` | 快照/ID 映射、候选构造、画布操作、回滚和载入事件适配 |
| `src/adapters/indigo/` | 浏览器 WASM provider 与化学诊断；保留原有立体提示处理 |
| `src/client/editor-bridge.ts` | iframe 命令请求、超时、回执与关闭清理 |

原根目录业务文件成为薄转导出层；`src/index.ts` 负责宿主装配，`editor.tsx` 保留界面与交互状态。元素、操作和桥接常量集中定义，未新增第二套执行器或存储。画布操作在适配器内失败时先回滚，正式保存失败仍走原有回滚/重试链路。

`scripts/check-architecture.mjs` 使用 TypeScript AST 检查相对依赖、外部包、转导出和动态导入，包含对旧薄转导出层的分类。构建时自动检查；违规依赖使构建在打包前失败。`check:types` 对源码做无输出类型检查，新增的 `@types/node` 仅为开发依赖。

- `pnpm test`：20 项通过，0 失败、0 跳过。
- `pnpm run test:browser`：最终构建的 P0、P1、P2、P3、完整修改/续接和主工作区布局六组全部返回 `ALL-PASS`。覆盖真实 Ketcher/Indigo 的候选、保存失败回滚/重试及连续手工/AI 撤销。
- `pnpm install --frozen-lockfile --ignore-scripts --offline`：通过，新增开发类型依赖已精确锁定，运行依赖版本不变。
- 重构前后一次性合同比对：包入口导出、四个工具的参数/output schema、描述、并发标志相同；普通批注、真实补充和多行要求的提示词内容相同。

## 当前边界

A0 没有新增公开工具、动态片段、草稿会话或通用图编辑。原有五类操作、九种基团、2–8 步 batch 及原冻结目标限制继续有效。v1 文档和批注存档版本保持不变。

本轮验证使用真实 Ketcher/Indigo 浏览器实例与确定性 Agent fixture；未重新调用真实官方 DSH 模型，未重启 Desktop 或验证原生窗口。历史真实 Agent/原生验收不能描述为本轮重测。A1 及之后的新流程仍需按规划完成原型和真实 Agent 验收。
