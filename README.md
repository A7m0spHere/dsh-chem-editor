# dsh-chem-editor

DeepSeek Harness 桌面端的分子编辑器。当前版本 `0.1.0`，完成 P0–P3：二维编辑、中英文界面、保存恢复，以及 Agent 对原子、键和框选片段的局部修改预览。[English](./README.en.md)

## 体验

在官方 DSH 桌面端打开任意会话，点击会话标题旁的六边形「分子」按钮。编辑器出现在右侧面板，可使用 DSH 自带的面板全屏、折叠及关闭按钮。

1. 点击「苯」示例。
2. 保持左侧矩形选择工具，点击苯环一个顶点。
3. 底部显示 `C #编号`；默认替换元素是 `N`。
4. 点击「替换选中原子」，再点击「撤销」或「重做」。

也可载入阿司匹林或含手性多环示例、粘贴 SMILES、打开 MOL/KET/项目文档、手工编辑并导出项目文档/KET/MOL/SMILES/SVG。非法价态或超出支持范围的修改会被拒绝。

默认使用简体中文，右上角可切换 English。中文覆盖插件面板、Ketcher 工具提示、常用属性/设置/导出对话框；化学符号、格式名称、输入数据和结构文件不翻译。当前锁定版本通过插件翻译层实现中文，专业标识和化学引擎原始诊断可能保留英文。

## 保存和恢复

每个 DSH 会话拥有一份独立文档。修改结构或文档名称后自动保存，也可点击「立即保存」。状态显示「已保存」后，关闭重开面板、刷新或重启 DSH 都能恢复结构、名称和语言。

文档保存到会话工作区的 `.chem-editor/<会话标识的 SHA-256>.json`，包含 KET、文档元数据和版本。无工作区会话使用 DSH 用户目录下的 `chem-editor/documents`。磁盘文件是正式存档；localStorage 仅保存界面语言偏好。

保存使用临时文件、flush 和替换，失败保留原文件并显示未保存状态。同一会话的多窗口写入使用内容版本检查；冲突时可以先导出当前结构，再「重新载入已保存版本」。不会自动覆盖另一窗口的修改。存档损坏时停止恢复和写入，保留原文件。

「项目文档」导出生成 `.chem.json`，可在另一个会话导入，带回结构和文档名称。撤销历史只在本次编辑器运行期间保留，重开或重启后从存档开始；旧选区编号会清除。

## Agent 批注（P3）

在当前 DSH 会话打开分子面板，选择普通原子、键或用矩形选择工具框选局部，等待结构显示「已保存」。在底部批注框输入“把选中的碳原子替换为氮原子”，点击「交给 Agent」。插件将要求发送到当前会话的已配置 Agent，并提供冻结选区。

Agent 调用 `chem_get_context` 和 `chem_propose_edit` 后，面板显示修改前后结构。预览生成时原画布保持；你点击「应用修改」才会提交并保存，也可以「取消批注」。应用使用同一编辑历史，可撤销。

每个会话同时一条批注，支持以下四种操作：元素替换、普通键级 1/2/3 修改、在单个原子上添加 OH/CH3/NH2/F/Cl（固定模板，单键连接）、删除冻结选区中的原子和键。删除预览会列出断开的边界键。快捷按钮可以填入批注，再点击「交给 Agent」。复杂片段替换留到 P4。提交后选择别的原子不会改变这条批注的目标。结构或文档版本变化、编辑器关闭或重启，会使旧批注失效。模型没有生成支持的方案、请求失败或超时，会显示失败状态。

批注及其冻结上下文保存到同目录的 `<会话标识的 SHA-256>.annotations.json`，保留最近 20 条。原子目标绑定当次编辑器实例。应用回执随分子文档原子保存，重复提交同一个应用不会修改两次。仅显示用的 Ketcher 选中标记和可省略空数组不算化学变化；其他原子、键和立体字段仍受检查。

## 当前范围

- 四类局部操作均先检查并预览；只有「应用修改」提交。删除所有选中原子可以清空画布，仍能一步撤销。
- 不重写整个分子的 SMILES。程序基于冻结 KET 执行确定操作，核对未改区域的原子、键、二维坐标、电荷、同位素和立体字段。
- 改芳香环键级、断开芳香体系、影响邻接立体中心、重叠原子或特殊模板的拓扑操作会明确拒绝。原结构已有且未变化的立体诊断会在预览中显示；新出现的诊断会拒绝。
- Ketcher 的手工绘图和原生撤销仍可使用；程序修改进入同一历史。
- 结构和选区通过 DSH 的 authenticated RPC 同步到宿主；文档写入工作区；提交批注时才调用当前会话的模型。
- 原子 ID 仅在当前结构版本内有效；每次操作读取当前选区，并检查异步验证期间是否发生结构变化。
- 面板折叠/会话切换保留已打开的编辑器；关闭重开或应用重启恢复已保存分子。未保存时关闭面板会被阻止。
- 不对包含 S-group/R-group、查询或伪原子的结构提供程序替换。

## 开发与安装

```powershell
pnpm install --frozen-lockfile
pnpm run build
pnpm test
```

浏览器验收需要 Chrome：运行 `pnpm run test:browser`，脚本会自动启动隔离测试服务器并清理测试工作区。成功结束输出 P0、P1、P2、P3 的 `ALL-PASS`。`node scripts/preview.mjs` 仅用于查看独立编辑器预览，不提供 DSH 自动保存。

构建后安装到官方桌面端（将 CLI 和项目路径换成自己的路径）：

```powershell
$env:DSH_HOME=Join-Path $env:USERPROFILE '.dsh'
& 'D:\dsh\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop add 'D:\AI项目\dsh-chem'
```

已验证目标：官方 DSH `0.2.0-rc.2`；Ketcher 三个包锁定 `3.7.0`。

宿主入口和 client 入口遵循 DSH bundle 机制。Ketcher 位于独立 iframe，React/CSS 与 DSH 隔离；插件在自己的宿主进程内启动仅绑定 `127.0.0.1` 的临时静态资源服务，不启动额外的 Python 或 Indigo Server。页面只加载本地构建资源，服务随插件卸载关闭。

## 验证依据

浏览器测试实际鼠标点选，比较修改前后的原子/键/立体属性，并通过 InChI 核对苯改 N 的产物为吡啶。覆盖非法价态不修改文档、撤销/重做、含手性复杂结构、KET 回读及手工/程序编辑连续撤销。KET 回读允许小于 `1e-5` 的坐标舍入差异，其余字段必须一致。

P1 额外覆盖工作区存档、关闭重开、刷新、会话隔离、中文提示与对话框、语言切换、项目/SVG 导出、保存失败重试、过期窗口冲突和损坏文件保护。P2 覆盖批注冻结、预览、应用保存、取消、过期拒绝、非法价态和幂等性；通过官方 DSH 临时 Web 配置完成真实 DeepSeek Agent 验证，并在官方桌面端实际完成批注、预览、应用保存和撤销。

详见 [P0 验收记录](./P0_ACCEPTANCE.md)、[P1 验收记录](./P1_ACCEPTANCE.md) 、[P2 验收记录](./P2_ACCEPTANCE.md) 和 [P3 验收记录](./P3_ACCEPTANCE.md)。P3 验证覆盖五种基团、单/双/三键、框选/内部原子/键/整图删除、边界说明、立体保护、提交失败回滚和重试、连续手工/AI 撤销。升级后完整退出官方桌面端并重开，以加载新的宿主工具。

使用了 EPAM Ketcher 与 Indigo（Apache-2.0）；第三方依赖的许可声明随构建保留。完整后续计划见 [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md)。

源码仓库不保存 `lib/`、`dist/` 和本机验证日志；克隆后先安装依赖并构建。`pnpm pack` 会自动构建并将运行所需的 `lib/`、`dist/` 打入插件包。
